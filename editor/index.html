Charter

A .charter file carries a document, a key, and a signed history, and it makes three claims: these are the bytes, these signatures were made by the key the file carries, and this history is continuous with that document. This page shows what a file claims and whether the claim holds, using the verifier in ../verifier/ — the same code charter verify runs. It is a demonstration of the format, not an editor to keep your notes in: nothing is stored, nothing is synced, and nothing is sent anywhere.

The key is read in this page and held in memory while you work: not stored, not written to localStorage, not remembered when the page closes. Holding a private key is your decision each time, which is why there is no "remember this key".
